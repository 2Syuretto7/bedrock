# Bedrock

A personal university for one learner. It starts at place value and ends at the engineering done at frontier AI labs and top technology companies, in seven tracks: Foundations, Software engineering, Distributed systems and cloud, Data engineering, MLOps, Hardware and HPC, and Security and reliability.

Bedrock mirrors [Axiom](https://github.com/2Syuretto7/axiom): the same stack, lesson form, tutor, recall, mastery and checks, with new subject matter.

This file is the only thing here so far. Phase 0, the engine with the first cluster of lessons, arrives in the first pull request, together with AGENTS.md and ROADMAP.md.
